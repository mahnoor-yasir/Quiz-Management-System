# Console-Based Quiz Management System

A console-based Quiz Management System developed in C++. The project allows users to attempt quizzes from multiple subjects including Mathematics, C, C++, and Python.

## Features
- Multiple quiz categories
- Score calculation
- Pass/Fail result generation
- Interactive console interface
- Subject selection system
- User information handling
- Colorful console design using `system("color")`

## Subjects Included
- Mathematics
- C Language
- C++
- Python

## Technologies Used
- C++
- Object-Oriented Programming
- Functions and Arrays
- Conditional Statements
- Loops

## How to Run
1. Open the project in Dev-C++ or any C++ IDE.
2. Compile the `.cpp` file.
3. Run the program.
4. Enter your details and start the quiz.
